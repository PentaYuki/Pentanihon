## 1. 特別な読み方をする漢字の言葉 (Từ Đọc Đặc Biệt - Jukujikun & Ateji)

| Từ Kanji | Cách đọc đặc biệt | Ghi chú |
| :--- | :--- | :--- |
| **今日 / 昨日 / 明日** | `きょう / きのう / あした・あす` | 熟字訓 (ghép chữ đọc đặc biệt theo nghĩa, không theo âm đơn lẻ) |
| **一昨日 / 明後日** | `おととい / あさって` | Hôm kia / Ngày kia |
| **今年 / 去年 / 一昨年** | `ことし / きょねん / おととし` | Năm nay / Năm ngoái / Năm kia |
| **大人 / 仲人 / 一人 / 二人** | `おとな / なこうど / ひとり / ふたり` | Các từ ghép có 人 đọc đặc biệt |
| **二十歳 / 二十日 / 一日 / 八日** | `はたち / はつか / ついたち / ようか` | Số tuổi và ngày mồng trong tháng |
| **従兄弟 / 姉妹 / 兄弟 / お兄さん・お姉さん** | `いとこ / しまい / きょうだい / おにいさん・おねえさん` | Xưng hô gia tộc rất hay bẫy |
| **田舎 / 土産 / 部屋 / 八百屋** | `いなか / みやげ / へや / やおや` | Từ vựng sinh hoạt kinh điển |
| **紅葉 / 梅雨 / 浴衣 / 七夕** | `もみじ / つゆ / ゆかた / たなばた` | 4 mùa và trang phục truyền thống |
| **為替 / 相撲 / 海老 / 真面目** | `かわせ / すもう / えび / まじめ` | Từ N2-N3 rất dễ bẫy reading |
| **上手 / 下手 / 風邪 / 怪我** | `じょうず / へた / かぜ / けが` | Ateji cơ bản buộc phải thuộc lòng |
| **時計 / 眼鏡 / 笑顔 / 果物** | `とけい / めがね / えがお / くだもの` | Đồ vật & thực phẩm thường nhật |

## 2. 訓読みが二つ以上ある漢字 (Chữ Có Nhiều Âm Kun)

| Kanji | Các âm Kun cần nhớ | Ví dụ phân biệt |
| :---: | :--- | :--- |
| **<span style='font-size:1.3em'>生</span>** | `い（きる）・う（まれる）・は（える）・なま・き` | 生きる (sống) / 生まれる (sinh) / 草が生える (cỏ mọc) / 生魚 (cá sống) / 生地 (vải, bột) |
| **<span style='font-size:1.3em'>上</span>** | `うえ・あ（がる）・のぼ（る）・かみ` | 上がる (tăng) / 坂を上る (lên dốc) / 川上 (thượng nguồn) |
| **<span style='font-size:1.3em'>下</span>** | `した・さ（がる）・くだ（る）・お（りる）・しも` | 下がる (giảm) / 下る (đi xuống/ra lệnh) / 車を下りる (xuống xe) |
| **<span style='font-size:1.3em'>空</span>** | `そら・あ（く）・から・す（く）` | 青空 (trời xanh) / 席が空く (trống ghế) / 空っぽ (trống rỗng) / お腹が空く (đói) |
| **<span style='font-size:1.3em'>開</span>** | `ひら（く）・あ（く）・あ（ける）` | 会を開く (tổ chức họp) / ドアが開く (cửa mở) |
| **<span style='font-size:1.3em'>通</span>** | `とお（る）・かよ（う）` | 道を通る (đi qua đường) / 大学に通う (đi học hàng ngày ở ĐH) |
| **<span style='font-size:1.3em'>重</span>** | `おも（い）・かさ（ねる）` | 重い荷物 (hành lý nặng) / 努力を重ねる (chồng chất nỗ lực) |
| **<span style='font-size:1.3em'>早 / 速</span>** | `はや（い）・すみ（やか）` | 朝が早い (sớm) vs スピードが速い (nhanh) vs 速やかに (nhanh chóng) |
| **<span style='font-size:1.3em'>細 / 狭</span>** | `ほそ（い）・こま（かい）・せま（い）` | 道が細い (hẹp dài) / 細かいお金 (tiền lẻ) / 部屋が狭い (phòng hẹp) |
| **<span style='font-size:1.3em'>着</span>** | `き（る）・つ（く）` | 服を着る (mặc áo) / 駅に着く (tới ga) |
